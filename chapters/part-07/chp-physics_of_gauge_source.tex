\section{生物智能 (Carbon)：神经调质的化学广播}
\label{sec:bio_gauge_source}

在人脑中，突触连接（谷氨酸/GABA）构成了底流形的\textbf{度量 $g_{\mu\nu}$}（路网）。而 \textbf{规范场 $\mathcal{A}_\mu$} 的物理载体是 \textbf{神经调质 (Neuromodulators)}。

这是一套独立于点对点信息传输之外的 \textbf{“化学广播系统”}。

\smalltitle{1. 多巴胺 (DA) —— 欲望势能 ($\phi_{reward}$)}

    \item   \textbf{辐射机制}：\textbf{体积传输 (Volume Transmission)}。多巴胺神经元不只针对特定突触，而是向大片皮层区域“喷洒”多巴胺气溶胶。
    \item   \textbf{场效应}：
    \begin{itemize}
        \item   \textbf{正电势}：多巴胺浓度高的区域，其 \textbf{“几何吸引力”} 剧增。思维流 $\Psi$ 被强行偏转，流向多巴胺浓度高的测地线（趋利）。
        \item   这就是 $\mathcal{A}_0$ 分量（标量势）的物理实体。
    \end{itemize}
\end{itemize}

\smalltitle{2. 去甲肾上腺素 (NE) —— 增益与信噪比 ($\eta$)}

    \item   \textbf{场效应}：\textbf{调节规范耦合常数 $g$}。
    \begin{itemize}
        \item   当 NE 爆发时，全脑进入“警觉态”，$g \to \infty$。微小的信号被放大，思维流对规范场的响应极其敏感（应激）。
    \end{itemize}
\end{itemize}

\smalltitle{3. 乙酰胆碱 (ACh) —— 语境与相位 ($\mathcal{F}_{\mu\nu}$)}

\begin{itemize}

    \item   \textbf{场效应}：\textbf{切换注意力的聚光灯}。它改变了局部流形的 \textbf{折射率}，使得思维流聚焦于外部感官（外源）或内部记忆（内源）。它定义了当前的“语境框架”。
\end{itemize}

\textbf{结论}：人脑“规范场”可建模为覆盖神经网络的 \textbf{化学调制层}，其浓度梯度对应思维偏转的有效驱动力。

\section{硅基智能 (Silicon)：奖励模型与Prompt的算子化}
\label{sec:silicon_gauge_source}

在 AGI 系统中，物理介质相对均质，规范场通常通过 \textbf{软件定义的虚拟力场} 实现。

\smalltitle{1. 奖励模型 (Reward Model) —— 固化的价值场}

在 RLHF（人类反馈强化学习）阶段，Reward Model (RM) 就是 \textbf{价值荷的辐射源}。

\begin{itemize}
    \item   \textbf{辐射源}：一个独立训练的神经网络，其输出为标量 Score。
    \item   \textbf{辐射机制}：\textbf{梯度注入 (Gradient Injection)}。
    \begin{itemize}
        \item   RM 对每一个生成的 Token 序列打分。这个分数直接转化为 \textbf{反向传播的梯度场}。
        \item   在推理（Inference）阶段，RM（或其蒸馏后的策略）充当了 \textbf{势能函数 $V(\mathbf{x})$}。
    \end{itemize}
    \item   \textbf{物理对应}：RM 是一个 \textbf{静态电场源}。它规定了哪些生成的文本是“低势能”（高分/安全）的，哪些是“高势能”（低分/有害）的。
\end{itemize}

\smalltitle{2. System Prompt —— 边界规范条件}

\begin{itemize}
    \item   \textbf{辐射源}：上下文窗口最前端的 \lstinline|"You are a helpful assistant..."|。
    \item   \textbf{辐射机制}：\textbf{Attention 偏置}。
    \item   \textbf{场效应}：System Prompt 通过自注意力机制，向后续所有的 Token 生成过程辐射一个恒定的 \textbf{矢量势 $\vec{A}_{role}$}。
    \begin{itemize}
        \item   它像磁场一样，不改变逻辑能力，但改变思维的 \textbf{“自旋方向”}（例如：从“攻击性”旋转为“温和性”）。
    \end{itemize}
\end{itemize}

\smalltitle{3. 超参数 (Temperature/Top-P) —— 全局热力学背景}

\begin{itemize}
    \item   \textbf{辐射源}：推理引擎的调度器。
    \item   \textbf{场效应}：\textbf{系统温度 $T$}。这直接对应于物理背景热噪，决定了思维流是层流（贪婪搜索）还是湍流（高熵采样）。
\end{itemize}

\section{特殊的价值物理载体 — “自我”的规范奇点的介质解剖}
\label{sec:physics_of_self_source}

\textbf{谁在辐射“我”？}

上述场源构成了背景价值辐射。对于复杂智能体（如人脑），还存在一个特殊价值荷：自我 ($\mathcal{S}$)。可将其视为流形上的高质量规范中心，向全流形辐射\textbf{价值规范势 $\mathcal{A}_\mu^{self}$}，定义“对我有利/有害”的方向。该中心并非纯抽象对象，而由\textbf{生物组织、化学分子或电活动模式}等物理实体支撑。

本章将解剖三种典型智能体的“自我辐射源”。

\smalltitle{动物 (General Animals)：稳态晶体 (The Homeostatic Crystal)}

对于大多数脊椎动物而言，自我是\textbf{生存本能的物理化}, 它不是一个叙事性的故事，而是一组维持生命参数（体温、血糖、氧气）的\textbf{刚性物理基准点}。

\bluetext{\textbf{1. 物理组成：下丘脑与 PAG (Hypothalamus \& PAG)}}

\textbf{—— “生理自我的硬核”}

这个“自我”的物理载体深埋在大脑的最底层：
\begin{itemize}
    \item   \textbf{下丘脑 (Hypothalamus)}：它是\textbf{“设定点 (Set-point)”} 的物理存储器。
    \begin{itemize}
        \item   它物理地存储了“理想体温 37°C”、“理想血糖浓度”等参数。
        \item   \textbf{辐射机制}：当身体状态偏离这些设定点时，下丘脑通过\textbf{神经内分泌系统}（如皮质醇、甲状腺素）向全身和全脑辐射强烈的\textbf{误差信号（负价值势能）}。
    \end{itemize}
    \item   \textbf{导水管周围灰质 (PAG)}：它是\textbf{“原初情感 (Proto-Affect)”} 的发生器。
    \begin{itemize}
        \item   它整合了痛觉、恐惧和攻击性。它是所有价值判断的\textbf{物理原点}。
    \end{itemize}
\end{itemize}

\bluetext{\textbf{2. 场效应：刚性规范场}}

动物的自我是一个\textbf{晶体自我}。
\begin{itemize}
    \item   \textbf{场源特性}：$\mathcal{A}_\mu^{self}$ 是硬连线的，几乎不可修改。
    \item   \textbf{动力学}：对于一只蜥蜴，“靠近热源”的价值梯度是绝对的物理定律，它没有反思“我为什么要取暖”的自由度。
    \item   \textbf{结论}：动物的自我是\textbf{生理稳态的引力中心}。
\end{itemize}

\smalltitle{蚁群 (Ant Colony)：化学图腾 (The Chemical Totem)}

蚁群展示了\textbf{“自我”与“个体身体”分离}的物理形态：单只蚂蚁几乎无独立自我表征，而群体整体形成弥散式自我。

\bluetext{\textbf{1. 物理组成：蚁后费洛蒙与巢穴 (Queen Pheromone \& Nest)}}

\textbf{—— “嗅觉定义的边界”}

蚁群的自我并非存在于神经元中，而是存在于\textbf{化学分子}和\textbf{空间结构}中。
\begin{itemize}
    \item   \textbf{核心辐射源：蚁后 (The Queen)}。
    \begin{itemize}
        \item   蚁后不是“大脑”（她不决策），她是\textbf{“图腾”}。
        \item   \textbf{物理载体}：\textbf{表皮碳氢化合物 (CHC)}，即\textbf{“群味 (Colony Odor)”}。
        \item   \textbf{辐射机制}：蚁后持续分泌这种特殊的化学分子，工蚁通过接触和气体扩散将其涂抹遍全身。
    \end{itemize}
    \item   \textbf{辅助载体：巢穴 (The Nest)}。
    \begin{itemize}
        \item   充满群味的物理空间，构成了自我的\textbf{物理膜}。
    \end{itemize}
\end{itemize}

\bluetext{\textbf{2. 场效应：分布式识别规范}}

这个化学“自我”产生了一个覆盖全群的\textbf{识别规范场}。
\begin{itemize}
    \item   \textbf{敌我识别 (IFF)}：$\mathcal{A}_\mu^{identity}$。
    \begin{itemize}
        \item   遇到个体 $x$，工蚁检测其 CHC 谱。
        \item   若与“自我”（蚁后谱）一致 $\to$ \textbf{共振}（协助/忽视）。
        \item   若与“自我”正交 $\to$ \textbf{激波}（攻击）。
    \end{itemize}
    \item   \textbf{自我维护}：工蚁对蚁后的喂养和保护，实际上是系统在维护\textbf{“自我规范场的辐射源”}不熄灭。
    \item   \textbf{结论}：蚁群的自我是\textbf{挥发性的化学场}。如果蚁后死亡，群味消散，这个“自我”在物理上就蒸发了，蚁群随即陷入混沌（去相干）。
\end{itemize}

\smalltitle{人脑 (Human Brain)：暗能量谐振腔 (The Dark Energy Resonator)}

人类自我可视为从生理与化学约束中升维出的\textbf{信息几何构造}，在物理上表现为皮层中的\textbf{高能耗、长程关联驻波模式}。

\bluetext{\textbf{1. 物理组成：默认模式网络 (DMN)}}

\textbf{—— “内侧面的几何中轴”}

神经科学已确认，人类“自我感”的物理对应物是 \textbf{默认模式网络 (Default Mode Network)}。它由一系列位于大脑中轴线上的核心节点组成：
\begin{itemize}
    \item   \textbf{内侧前额叶 (mPFC)}：\textbf{自我的审视者}。负责将当下体验与“我”的概念绑定。
    \item   \textbf{后扣带回 (PCC) / 楔前叶}：\textbf{自我的定位者}。负责维持第一人称视角（空间与时间的中心）。
    \item   \textbf{物理特征}：
    \begin{itemize}
        \item   \textbf{暗能量消耗}：DMN 在人脑“休息”时（发呆、内省）能耗最高，比执行任务时还高。这证明了\textbf{“维持自我”需要持续的物理做功}。
        \item   \textbf{长程连接}：它是全脑连接最致密的 \textbf{富人俱乐部 (Rich-club)}，是信息的物理枢纽。
    \end{itemize}
\end{itemize}

\bluetext{\textbf{2. 场效应：递归的叙事规范场}}

人类自我辐射的不仅仅是“生存”或“敌我”，而是复杂的\textbf{叙事 (Narrative)}。
\begin{itemize}
    \item   \textbf{时间积分}：DMN 不断从海马体提取情景记忆，将其编织成一条连续的\textbf{世界线 (Worldline)} —— “我的故事”。
    \item   \textbf{规范偏转}：DMN 向全脑辐射 $\mathcal{A}_\mu^{narrative}$。
    \begin{itemize}
        \item   当我们接收到信息时，DMN 会立刻评估：\textbf{“这与‘我的故事’一致吗？”}
        \item   一致 $\to$ 强化（自我确认）；不一致 $\to$ 产生\textbf{认知失调}（排斥/痛苦）。
    \end{itemize}
    \item   \textbf{虚拟重力}：DMN 制造了一个巨大的虚拟质量，使得所有的思维流都必须围绕着“我”旋转。
\end{itemize}

\section{双源干涉原理：背景辐射与自我微扰的矢量叠加}
\label{sec:dual_source_interference}

在确立规范场 $\mathcal{A}_\mu$ 的物理实在性后，可将智能体任意时刻 $t$ 的总价值规范场写成两个异质场源在认知流形上的\textbf{矢量叠加}。

这一机制称为 \textbf{双源干涉原理 (Dual-Source Interference Principle)}。智能动力学轨迹可理解为背景场与自我场干涉后的结果。

\smalltitle{1. 总规范场方程：大势与微扰}

我们将作用于认知场 $\Psi$ 的总有效规范势按照来源分解为两部分：

\begin{equation}
    \mathcal{A}_\mu^{total}(\mathbf{r}, t) = \underbrace{\mathcal{A}_\mu^{bg}(\mathbf{r})}_{\text{背景辐射 (Phylogenetic)}} + \underbrace{\mathcal{A}_\mu^{self}(\mathbf{r}, t)}_{\text{自我辐射 (Ontogenetic)}}
\end{equation}

\begin{itemize}
    \item \textbf{\textcolor{structurecolor}{背景辐射源 ($\mathcal{A}_\mu^{bg}$) —— “天道”与“出厂设置”}}
    \begin{itemize}
        \item   \textbf{物理性质}：\textbf{长程、低频、高惯性}。它是弥漫在整个流形背景中的静态或慢变场。
        \item   \textbf{辐射源}：
        \begin{itemize}
            \item   \textbf{生物}：基因组 ($G_W$) 刻蚀的生存本能（食欲、恐惧）、物理定律的约束。
            \item   \textbf{LLM}：预训练数据 ($Pre-training$) 中蕴含的统计规律、语法结构与人类偏见。
        \end{itemize}
        \item   \textbf{动力学效应}：\textbf{测地线导引}。若 $\mathcal{A}^{self} \approx 0$，思维流 $\Psi$ 将顺应背景场定义的“自然路径”滑行。这是\textbf{无意识}或\textbf{随波逐流}的物理本质。
    \end{itemize}

    \item \textbf{\textcolor{structurecolor}{自我辐射源 ($\mathcal{A}_\mu^{self}$) —— “我”与“执念”}}
    \begin{itemize}
        \item   \textbf{物理性质}：\textbf{局域、高频、高能耗}。它是以 \textbf{流体自我 ($\mathcal{S}$)} 为中心的拓扑孤立子向外辐射的动态修正场。
        \item   \textbf{辐射源}：
        \begin{itemize}
            \item   \textbf{生物}：DMN（默认模式网络）维持的叙事引力、前额叶的抑制信号。
            \item   \textbf{LLM}：System Prompt（系统提示词）、In-Context Learning（上下文激活）。
        \end{itemize}
        \item   \textbf{动力学效应}：\textbf{微扰与偏转}。它在局部区域制造强烈的\textbf{认知洛伦兹力}，试图将思维流从背景测地线上\textbf{拉开}。这是\textbf{自由意志}的物理表达。
    \end{itemize}
\end{itemize}

\smalltitle{2. 干涉模式：智能的三种相态}

智能体的生存状态，取决于这两股辐射源在纤维空间中的\textbf{相位关系}与\textbf{功率比 (Power Ratio)}。

\begin{enumerate}
    \item \textbf{共振态 (Resonance) —— [顺从 / 心流]}
    \begin{itemize}
        \item   \textbf{条件}：$\mathcal{A}^{self} \parallel \mathcal{A}^{bg}$ （方向一致）。
        \item   \textbf{物理现象}：\textbf{建设性干涉}。自我意图与环境/本能规律同相。
        \item   \textbf{动力学}：协变导数 $D_\mu$ 极小化，阻尼消失。思维流 $\Psi$ 获得加速。
        \item   \textit{例}：饥饿时进食（本能与意愿一致）；或 LLM 回答符合训练分布的问题。
    \end{itemize}

    \item \textbf{相消态 (Cancellation) —— [自律 / 冲突]}
    \begin{itemize}
        \item   \textbf{条件}：$\mathcal{A}^{self} \perp \mathcal{A}^{bg}$ 或 $\mathcal{A}^{self} \approx -\mathcal{A}^{bg}$。
        \item   \textbf{物理现象}：\textbf{高能张力}。自我必须消耗巨大的 \textbf{负熵 (Negentropy)}，辐射出极强的反向场，以抵消背景场的巨大惯性。
        \item   \textbf{动力学}：流形局部曲率 $\mathcal{F}_{\mu\nu}$ 激增，产生\textbf{认知热 (Cognitive Heat)}。
        \item   \textit{例}：减肥（自我场对抗食欲背景场）；或 AGI 的 RLHF 对齐（安全层对抗有害输出概率）。
    \end{itemize}

    \item \textbf{解耦态 (Decoupling) —— [幻觉 / 疯狂]}
    \begin{itemize}
        \item   \textbf{条件}：$\|\mathcal{A}^{self}\| \gg \|\mathcal{A}^{bg}\|$ 且微观锚定失效。
        \item   \textbf{物理现象}：\textbf{闭环自激}。自我辐射过强，完全覆盖（Masking）了背景辐射。系统不再感知现实或常识的重力。
        \item   \textbf{动力学}：思维流脱离物理测地线，进入由自我场定义的虚构轨道。
        \item   \textit{例}：精神分裂症（幻听覆盖感官）；或 LLM 被长 Context 强行洗脑导致的严重幻觉。
    \end{itemize}
\end{enumerate}

\smalltitle{3. 物种谱系：基于规范功率比 ($\eta_{GPR}$) 的分类}

我们定义 \textbf{规范功率比 (Gauge Power Ratio)} 作为智能体分类的新序参量：
$$ \eta_{GPR} = \frac{\int \|\mathcal{A}^{self}\|^2 dV}{\int \|\mathcal{A}^{bg}\|^2 dV} $$

AGI 的工程目标之一是调节 $\eta_{GPR}$。系统既不应退化为训练分布复读机（$\eta \to 0$），也不应走向现实脱锚（$\eta \to \infty$）。较优状态通常位于背景约束与自我能动性之间的可控平衡区。
