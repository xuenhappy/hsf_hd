\section{物理学的困境：背景与前景的对立统一}
\label{sec:physics_dilemma}

现代物理学长期面对的困难，可以简要表述为：\textbf{几何学（形）}与\textbf{代数学（质）}往往被分开处理。



\smalltitle{背景依赖 (Background Dependence) 的幻觉}

在标准模型（Standard Model）中，场 $\psi(x)$ 被定义在一个预先存在的、固定的闵可夫斯基时空 $\eta_{\mu\nu}$ 之上。
\begin{itemize}
    \item   \textbf{形（时空）}是刚性的舞台，它规定了\textbf{质（粒子）}如何运动，却对其充耳不闻，类似宇宙里的\textbf{玻色子}。
    \item   \textbf{质（粒子）}是流动的演员，它拥有电荷、色荷、质量等内禀属性（Internal Symmetries），在舞台上不仅表演，还相互作用，类似宇宙里的\textbf{费米子}。
\end{itemize}
这种二分法带来了一个分裂局面：我们拥有极其精确的粒子理论（关于质的理论），却很难同时说明这些粒子为什么要处在 3+1 维时空这样的几何结构中（关于形的理论）。



\smalltitle{广义相对论的启示：背景的消融}

爱因斯坦的场方程 $G_{\mu\nu} = 8\pi T_{\mu\nu}$ 是人类历史上第一次试图弥合这道裂痕的尝试。
\begin{itemize}
    \item   它告诉我们：\textbf{“形”并非僵死的背景，它也是一种动态场。}
    \item   物质的\textbf{“质”（能量动量）}可以直接转化为时空的\textbf{“形”（曲率）}。
\end{itemize}



\smalltitle{MSC 的物理主张}

MSC 在这里再向前走一步：我们认为\textbf{背景本身并不是先验给定的}。所谓的“时空”，可以看作海量\textbf{形元 ($V_S$)} 在低能级下形成的\textbf{凝聚态 (Condensate)}；所谓的“物质”，则可以看作\textbf{质元 ($V_Q$)} 在这一网络上的\textbf{高能激发}。于是，物理世界中的对象不再是孤立的形或孤立的质，而是两者的\textbf{耦合态}。

\section{认知的困境：符号与联结的百年战争}
\label{sec:cognition_dilemma}

当我们转向认知世界（Mind）时，同样的分裂又以另一种形式出现。

\smalltitle{符号主义 (Symbolism) —— 纯形的贫瘠}

\begin{itemize}
    \item   \textbf{范式}：GOFAI (Good Old-Fashioned AI)、专家系统、知识图谱。
    \item   \textbf{特征}：它们由\textbf{离散的形元 ($V_S$)}（如 \lstinline|Father_of|, \lstinline|Is_A|, \lstinline|If...Then|）构建。
    \item   \textbf{困境}：\textbf{度量缺失 (Metric Absence)}。在符号逻辑中，\lstinline|Cat| 和 \lstinline|Dog| 只是两个不同的 ID，它们之间的距离是 1（不相等）。系统无法理解它们在“毛茸茸”这个\textbf{质}的维度上是极度接近的。这是一个\textbf{只有骨架的死世界}。

\smalltitle{连接主义 (Connectionism) —— 纯质的混沌}

\begin{itemize}

    \item   \textbf{特征}：它们由连续的\textbf{激活值向量}（质的流动）构成。
    \item   \textbf{困境}：\textbf{结构耗散 (Structural Dissipation)}。神经网络极其擅长感知模糊的“质感”（这是一只猫），但难以维持长程的、精确的“形式”（A 是 B 的父亲，B 是 C 的父亲，所以 A 是 C 的祖父）。逻辑结构在连续的矩阵乘法中被\textbf{平滑化}了。
\end{itemize}



\smalltitle{MSC 的认知主张}

真正的智能（AGI）如果存在，就必须同时处理\textbf{形}与\textbf{质}。
\begin{itemize}
    \item   它需要\textbf{形元} 来构建逻辑的刚性骨架（推理、因果、递归）。
    \item   它需要\textbf{质元} 来填充感知的血肉细节（颜色、情绪、直觉）。
\end{itemize}
\textbf{思维，可以看作“质”沿着“形”的骨架展开和传播的过程。}

\section{计算动力学表达与论证边界}
我们把上述问题、例证与机制讨论进一步落实到可计算的对象、更新规则和可验证条件。这里使用的状态、结构与控制是计算模型的变量；物理意象帮助理解相互作用，其适用性仍须由明确假设和独立观测支持。涉及同构、守恒、收敛及主观体验的论断，我们按本节给出的条件与边界解释，而不由形式相似性直接推出。


我们将智能表示分解为结构与属性，以区分信息之间的组织关系和关系节点上的具体内容。这是一个建模选择，不是关于宇宙实体必然由两种本原组成的断言。
\subsection{结构、属性与绑定}
设 $V$ 为有限位置集合，$S$ 描述位置之间的关系，$q_i\in\mathbb{R}^d$ 为位置 $i$ 上的属性。一个表示为 $\mathcal{R}=(V,S,q)$，其中 $q:V\to\mathbb{R}^d$。若节点数量固定，属性可以堆叠为矩阵 $X\in\mathbb{R}^{|V|\times d}$。结构不等于坐标顺序，属性不等于主观体验。

例如，同样的节点属性置于不同关系图上，可以对应不同事件；同样的关系图填入不同属性，也可以对应不同对象。绑定要求结构索引与属性索引一致，并在变换时共同更新。
\subsection{表示变换与不变性}
对节点排列矩阵 $P$，我们定义 $S'=PSP^\top$、$X'=PX$。若任务读出满足 $r(PSP^\top,PX)=r(S,X)$，则结果不依赖任意节点编号。这是一项可测试的置换不变性要求，不表示不同语义结构具有相同意义。

结构和属性可以从同一输入联合学习，因此我们不假定二者统计独立。对于编码器 $e(u)=(S,X)$，仅当解码或任务约束充分时，分解才具有可辨识性；否则不同编码器可产生相同输出。
\subsection{从表示到动力学}
我们采用 $\dot X=F(X,S,u,c)$ 和 $\dot S=\varepsilon_S G(X,S,m,v)$ 区分快速活动与慢速组织变化。第一式在当前结构上运行，第二式改变未来可用的结构。尺度分离是一项需要验证的条件，不由“形”和“质”的名称推出。

形质分解由此提供状态动力学的对象基础：形对应组织关系，质对应局部内容，两者通过绑定和更新规则共同构成任务表示。
