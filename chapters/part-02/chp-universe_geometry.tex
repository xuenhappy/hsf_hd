\chapter{结构化状态空间：图、纤维与张量表示}
\label{chp:universe_geometry}

在第二章和第三章中，我们分别讨论了“形”的结构和“质”的内容。现在的问题是，怎样把这两者放进同一个数学对象里。简单相加并不能解决这个问题，我们需要一个能够描述\textbf{“属性如何附着在结构上”}的框架。

这一章，我们将引入\textbf{纤维丛 (Fiber Bundle)}。它提供了一种自然的方式，把位置、关系和属性统一写进同一个几何描述之中。


\begin{bquote}
        \textbf{高维的织机}

    \vspace{1em}我们很容易把“红色”想成涂在“苹果”表面的一层东西，仿佛对象和属性原本彼此分离。但在这里，更合适的看法是：\textbf{“形”}给出位置与关系，\textbf{“质”}给出这些位置上可以出现的具体分量。两者不是先后拼装的零件，而是同一结构的两个方面。

    \vspace{1em}数学上，描述这种结构的合适语言就是\textbf{纤维丛 (Fiber Bundle)}。在这个模型里，每一个时空点都伴随着一个高维内空间，也就是\textbf{纤维}。颜色、温度、质量、电荷，以及更一般的属性分量，都可以看作这个纤维中的坐标方向。

    \vspace{1em}于是，世界不再只是一个平面的点集，而是一个带有内在层次的结构。每一个物体，都可以理解为这个结构中的一个\textbf{截面}。本章要说明的，就是如何用这种几何语言，把前面定义的“形”与“质”统一为一个严密的数学框架，并据此描述\textbf{实体 (Object)}。

\end{bquote}


\section{宇宙的拓扑解剖：四元组 \texorpdfstring{$(E, \pi, M, F)$}{(E, π, M, F)}}
\label{sec:topology_anatomy}

在 MSC 理论中，宇宙（以及任何复杂知识库）不再被看成一个简单集合，而是一个\textbf{纤维丛结构}。我们把它形式化为一个四元组：
$$ \mathcal{U} \equiv (E, \pi, M, F) $$


\smalltitle{底空间 (Base Space, $\mathcal{M}$) —— 形的领地}

\begin{itemize}
    \item   \textbf{对应}：\textbf{第二章定义的“形” ($\mathcal{S}$)}。
    \item   \textbf{数学定义}：一个拓扑流形（在离散情况下是单纯复形 $\mathcal{K}$）。
    \item   \textbf{记号约定}：本书中 $\mathcal{M}$ 与 $\mathcal{M}$ 指同一个“底流形/底空间”，此处为配合纤维丛四元组采用 $\mathcal{M}$。
    \item   \textbf{语义含义}：这是\textbf{“位置”}与\textbf{“关系”}的集合。它回答了 "Where" 和 "How related"。
    \begin{itemize}
        \item   \textit{物理例}：四维时空坐标 $(x, y, z, t)$。
        \item   \textit{AI例}：图像的像素网格，或知识图谱的节点拓扑。
    \end{itemize}
\end{itemize}



\smalltitle{纤维 (Fiber, $F$) —— 质的领地}

\begin{itemize}
    \item   \textbf{对应}：\textbf{第三章定义的“质” ($V_Q$)}。
    \item   \textbf{数学定义}：一个附着在 $\mathcal{M}$ 上每一点 $x$ 的向量空间（或李群）。
    $$ F_x \cong \mathbb{R}^k $$
    \item   \textbf{语义含义}：这是\textbf{“可能性”}的集合。它包含了在这个位置上\textit{可能}出现的所有属性（颜色、硬度、语义向量）。
    \item   \textbf{关键点}：对于底空间上的每一点，纤维的结构是\textbf{全同的}（所有地方都有定义颜色的能力）。
\end{itemize}


\smalltitle{全空间 (Total Space, $E$) —— 实体的栖息地}

\begin{itemize}
    \item   \textbf{定义}：形与质的\textbf{局部直积}。
    $$ E \approx\mathcal{M}\times F $$
    \textit{(注：这是局部拓扑，全局上可能会有扭曲，即非平凡丛)}
    \item   \textbf{语义含义}：这是\textbf{“状态空间”}。每一个点 $e \in E$ 代表了“在位置 $x$ 具有属性 $f$”这样一个具体的事实。
\end{itemize}

\smalltitle{投影算子 (Projection, $\pi$) —— 降维的观察}

\begin{itemize}
    \item   \textbf{定义}：一个从全空间映射回底空间的连续映射 $\pi: E \to M$。
    \item   \textbf{物理意义}：\textbf{“忽略细节”}。当我们只关心物体在哪里，而不关心它是什么颜色时，我们就在执行投影操作。
\end{itemize}


\section{实体即截面 (Object as Section)}
\label{sec:object_section}

在纤维丛的语言中，什么是我们眼中的“一个苹果”或“一个电子”？
答案是：\textbf{截面 (Section)}。

\smalltitle{截面的定义}

截面是一个连续映射 $\sigma:\mathcal{M}\to E$，它满足：
$$ \pi(\sigma(x)) = x, \quad \forall x \in\mathcal{M}$$
\begin{itemize}
    \item   \textbf{直观理解}：你在底流形 $\mathcal{M}$ 上行走（遍历空间），对于每一个位置 $x$，你都在垂直的纤维 $F_x$ 上\textbf{选取了一个具体的值} $\sigma(x)$。
    \item   \textbf{图景}：可以把它想成一片麦田。底空间是土地，纤维是麦秆；当每根麦秆都取到一个高度时，连起来形成的那个面，就是一个\textbf{截面}。
\end{itemize}

\smalltitle{实体的构成方程 (初步)}

一个具体的物理实体 $\mathbb{O}$，就是\textbf{质元在形流形上的分布函数}：
$$ \mathbb{O}(\mathbf{r}) = \sum_{k \in V_Q} J_k(\mathbf{r}) \cdot \mathbf{e}_k $$
这恰恰就是一个截面 $\sigma(\mathbf{r})$。
\begin{itemize}
    \item   \textbf{真空截面}：$\sigma_0(\mathbf{r}) = \mathbf{0}$。所有纤维上的取值都为零。
    \item   \textbf{激发截面}：$\sigma_{apple}(\mathbf{r})$。在苹果占据的空间区域 $\Omega \subset M$ 内，颜色纤维取值为“红”，硬度纤维取值为“硬”。
\end{itemize}
\textbf{结论}：\textbf{创造一个物体，就是在纤维丛中“切割”出一个特定的截面。}


\section{意义的动力学：联络 (\texorpdfstring{$\nabla$}{∇}) 与 平行移动}
\label{sec:meaning_dynamics}

纤维丛有一个很重要的优点：它能解释\textbf{“变化中的不变性”}。
当我把一个红苹果从桌子左边移到右边时，位置（形）变了，但红色（质）为什么没变？或者在某些语境下，词义是如何发生漂移的？

这需要引入 \textbf{联络 (Connection)}。


\smalltitle{埃雷斯曼联络 (Ehresmann Connection)}

联络定义了如何将纤维空间中的信息从一点 $x$ \textbf{平移} 到邻近点 $x + dx$。
它将全空间 $E$ 的切空间 $TE$ 分解为：
$$ TE = \text{Vertical Space} \oplus \text{Horizontal Space} $$
\begin{itemize}
    \item   \textbf{垂直部分}：属性的改变（比如苹果变色了）。
    \item   \textbf{水平部分}：位置的改变（伴随着属性的\textbf{平行移动}）。
\end{itemize}

\smalltitle{离散联络：图上的平行移动算子（可计算版本）}

由于本章主题是“离散纤维丛”，我们给出与上面连续写法一致的离散对应：
\begin{itemize}
    \item \textbf{离散底空间}：$\mathcal{M}$ 取为图 $G=(V,E)$ 或单纯复形的 1-骨架。
    \item \textbf{离散纤维}：每个节点 $v\in V$ 上有一份纤维向量空间 $F_v\cong\mathbb{R}^k$。
    \item \textbf{联络/传输}：对每条有向边 $(u\to v)$ 赋一个线性传输算子（离散联络）
    $$ U_{u\to v}\in GL(k) \ \ \text{(也可取 } U\in O(k)/U(k)\text{ 以表达某种“范数守恒”)} $$
    \item \textbf{平行移动}：沿路径 $\gamma=(v_0\to v_1\to\cdots\to v_n)$ 的平行移动为算子乘积
    $$ \mathsf{PT}_{\gamma} = U_{v_{n-1}\to v_n}\cdots U_{v_0\to v_1}, \quad \sigma(v_n) \approx \mathsf{PT}_{\gamma}\,\sigma(v_0) $$
\end{itemize}



\smalltitle{平行移动 (Parallel Transport) —— 语义的一致性}

当我们说“苹果移动了”时，我们是指它的\textbf{质向量}沿着底流形的路径 $\gamma$ 进行了\textbf{平行移动}。
$$ \nabla_{\dot{\gamma}} \sigma = 0 $$
\begin{itemize}
    \item   \textbf{物理含义}：在没有外力（规范场）干扰的情况下，物体的属性保持守恒。
    \item   \textbf{语义含义}：\textbf{类比推理 (Analogy)}。
    \item   \textit{例子}：“国王”之于“男人”等于“女王”之于“女人”。
    \item   \textit{几何解释}：将“国王”这个截面，沿着从“男”到“女”的路径（形的变化）进行平行移动，如果不发生扭曲，它应该重合于“女王”。
\end{itemize}



\smalltitle{曲率 (Curvature) —— 语境的张力}

如果在移动一圈回到原点后，属性变了（$\sigma_{final} \neq \sigma_{start}$），我们说这个空间存在\textbf{曲率}。
$$ \mathbf{F} = [\nabla_\mu, \nabla_\nu] $$
\begin{itemize}
    \item   \textbf{物理对应}：电磁场强度、引力场。
    \item   \textbf{语义对应}：\textbf{语境效应}。同一个词在不同上下文中意思不同，这代表语义流形是\textbf{弯曲}的。
\end{itemize}

\smalltitle{离散曲率：回路 holonomy 作为“语境效应”的度量}

在离散联络下，曲率最自然的可计算量是“走一圈回来偏了多少”，对一个回路 $\gamma$，定义 holonomy：
$$ U_{\gamma} = \mathsf{PT}_{\gamma} $$
若 $U_{\gamma}\neq I$，则表示回路中存在不可消去的扭曲；一个简单的强度指标是
$$ \kappa(\gamma) = \|U_{\gamma}-I\| $$
其直观语义是：同一个概念/属性沿不同语境路径绕行后回到“同一个词”，其意义向量不再重合，偏差越大，语境张力（曲率）越强。

\begin{bquote}
        \textbf{本章结语}：

    我们已经把这一章所需的几何框架搭了起来。
        \begin{itemize}
        \item \textbf{形 ($\mathcal{M}$)} 给出底空间;
        \item \textbf{质 ($F$)} 给出每一点上的属性空间;
        \item \textbf{纤维丛 ($E$)} 把两者组织为统一的总空间;
        \item \textbf{截面 ($\sigma$)} 描述一个具体对象的属性分布;
        \item \textbf{联络 ($\nabla$)} 规定这种分布如何在空间中保持或变化。
        \end{itemize}

现在，定义静态对象所需的几何部件已经齐备。下一章，我们将把这些部件进一步写成一个明确的\textbf{构成方程 (The Constitutive Equation)}，看看如何用简洁的张量表达，把前面的结构性直觉变成可操作的公式。
\end{bquote}

\section{计算动力学表达与论证边界}
我们把上述问题、例证与机制讨论进一步落实到可计算的对象、更新规则和可验证条件。这里使用的状态、结构与控制是计算模型的变量；物理意象帮助理解相互作用，其适用性仍须由明确假设和独立观测支持。涉及同构、守恒、收敛及主观体验的论断，我们按本节给出的条件与边界解释，而不由形式相似性直接推出。


我们建立结构化状态空间，以统一表达位置之间的关系和位置上的内容。表示选择由任务与实现决定。
\subsection{离散纤维表示}
给定位置集合 $V$，每个位置 $i$ 对应属性空间 $F_i$。总空间为 $\mathcal{E}=\bigsqcup_{i\in V}F_i$，投影 $\pi$ 返回位置。截面 $q$ 满足 $\pi(q(i))=i$。若所有 $F_i\simeq\mathbb{R}^d$ 且选定共同坐标，截面可表示为属性矩阵。

这里的离散表示不自动具有连续纤维丛的光滑性质。讨论可微联络或曲率之前，必须补充连续结构或定义离散对应物。
\subsection{跨位置传输}
令 $A_{ij}:F_j\to F_i$ 为传输映射，局部更新可以写为
\begin{equation}\dot q_i=\sum_{j\in\mathcal{N}(i)}w_{ij}(A_{ij}q_j-q_i)+f_i(q_i,u_i,c_i).\end{equation}
当 $A_{ij}$ 为恒等映射时，该式退化为内容扩散和局部反应。映射具有方向、类型或上下文依赖时，更新能够表达更丰富的关系，但稳定性需要针对具体算子分析。
\subsection{张量分解的适用范围}
若位置和内容可分离，表示可以写成 $s\otimes q$；一般状态为 $X=\sum_r s_r\otimes q_r$。单个张量积仅描述秩一可分离状态，不能单独证明不可分离的绑定。耦合由多项表示、非线性更新或约束产生，需明确其机制。
