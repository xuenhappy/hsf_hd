# HSF-HD 计算动力学改写规范

本规范用于作者逐章重写。结构拆分完成不代表理论审核完成。

## 理论位置

系统论、协同论、耗散结构理论、复杂系统理论与认知科学提供原则和经验约束；HSF-HD 构造智能状态动力学的模型族；AgentOS 实例化为可执行的记忆与调度机制。“一般空气动力学”是定位类比，不能替代模型的适用条件。

## 作者表达

正文使用“我们定义”“我们假设”“由此得到”“在这些条件下”等作者陈述。避免“原文错误”“建议作者”“本次修改”等审稿语言进入书稿。迁移状态和待改事项只进入 docs。

每章依次说明问题、对象、假设、更新机制、推导、边界、实现与验证。允许章节采用不同数学工具，但必须声明对象的空间、类型、尺度和可观测量。

## 公式与论证

- 区分定义、公理、建模假设、数学命题、经验假说和工程设计。
- 方程每项维度一致；符号首次出现定义空间、作用对象与时间尺度。
- 连续状态、概率分布、图编辑和事件记录分别建模。
- 有界、局部稳定、全局收敛、目标下降与任务成功分开证明。
- 随时间改变的目标、度量、结构和外部输入必须进入导数。
- 连续模型的性质必须通过步长或积分器条件传递到离散实现。
- 物理语言放在辅助解释中。状态强度、目标函数、信息熵、资源预算与焦耳能耗不可互换。
- 不由相似图形、共同目标或预测成功推导严格同构。
- 保留的历史公式仍需要逐条审核，不能因项目通过编译而视为成立。

## 术语方向

| 历史术语 | 一般计算表述 |
| --- | --- |
| 认知波函数、旋量场 | 状态场；复数或旋量仅用于声明了该结构的专门模型 |
| 目的论狄拉克方程 | 状态传播与目标控制方程 |
| 认知爱因斯坦场方程 | 状态—结构耦合方程 |
| 宏观意志 | 目标导向控制、元控制 |
| 认知能量 | 按具体含义区分活动强度、代价和实际能耗 |
| 负熵泵 | 按机制区分信息获取、反馈校正和资源供给 |
| 坍缩 | 决策提交、离散读出或状态选择 |
| 认知温度 | 指定分布中的尺度或探索强度 |
| 拓扑保护 | 明确不变量、扰动集合与保持条件 |

这里的表格不是全书自动替换词典。例如实际物理功耗和量子模型不能通过字符串替换改成计算代价。
