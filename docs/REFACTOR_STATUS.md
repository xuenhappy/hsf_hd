## 后续修订方法

每章先记录问题、例证、概念、公式、推导、插图和结论的对应关系，再逐节重写。禁止用纲要替换完整章节。每节至少完成问题背景、对象定义、机制展开、必要推导、例证及适用边界；不以固定字数填充，也不以减少页数为目标。

1. 第一卷：保留形质论述的思想深度，把关系结构、属性、绑定与跨域映射落实到计算对象，逐条处理物理统一和强同构的断言。
2. 第二卷：依次处理状态传播、控制稳定性、历史/记忆、多尺度更新、目标与自我模型；写出每项结论的条件。
3. 第三卷：区分观察、比较、架构设计与尚待验证的实现设想；把 HSF-HD 到 AgentOS 的映射具体化。
4. 附录：补齐符号、维度、推导条件与离散实现的接口，不删掉原有示例和实现材料。
5. 插图：保留原图，逐张补充阅读说明；原图内部的物理术语需要另行制作可核对的计算动力学标注，不能仅改图注后宣布完成。

`fluid_moe.py` 保持原文件，训练与运行正确性另需验证。
